# 야광(夜光) — 당신이 모르는 사이

서울과학기술대학교 2026 졸업전시 · 웹 인터랙션

손을 카메라에 비추면 손끝이 커서가 된다. 감각의 조각들이 담긴 아카이브를
훑다가 하나를 꾹 눌러 고르면, 그 영상이 구슬로 응축된다.

---


> 파일명을 영문으로 둔 이유 — 맥은 한글 파일명을 NFD(자모 분해형)로 저장하는데
> 브라우저는 NFC(조합형)로 요청한다. 로컬에서는 맞춰주지만 깃허브에 올리면
> 서로 다른 이름이 돼서 영상이 404 로 안 뜬다. 화면에 나오는 이름은
> `main.js` 의 `name` 이 따로 들고 있으니 한글 그대로다.

## 실행

카메라는 `https` 또는 `localhost` 에서만 열린다. 파일을 그냥 더블클릭하면
동작하지 않으니 반드시 로컬 서버로 띄울 것.

```bash
python3 -m http.server 5510
```

브라우저에서 `http://localhost:5510` 을 연다.
(`실행하기.command` 를 더블클릭해도 같은 일을 한다)

## 흐름

```
로딩 → 자원 아카이브 → 구슬 → 본편(0–26초) → 구슬빛 정원 → 본편(26초–끝) → 아카이브
```

- 아카이브에서 **오른쪽 목록 첫 칸에 손을 얹으면** 그 영상이 왼쪽 큰 화면으로 올라온다.
  목록은 큰 화면의 다음 순서대로 줄을 서고, 끝까지 가면 처음으로 돌아온다
- 큰 화면에 뜬 영상이 마음에 들면 **손가락을 모아 꾹 누르면** 선택된다
- 카메라가 없으면 **마우스를 움직이고 길게 눌러** 같은 조작이 된다
- 정원의 `다음 영상으로` 버튼은 구슬을 충분히 본 뒤에 나타난다
- 정원은 아카이브가 뜰 때 미리 띄워 두지만, 실제로 들어가는 순간 새로 띄운다.
  그러지 않으면 앞사람이 열어 본 구슬이 `읽은 기억` 에 그대로 남는다

## 구슬빛 정원에서 손댄 곳

자체 완결형 파일이지만 두 군데만 숫자를 고쳤다 (`Bx` · 카메라 프레이밍).

| 값 | 뜻 | 전 → 후 |
|---|---|---|
| `e.r*9.4` | 고른 구슬 앞에 서는 거리 (구슬 반지름의 배수) | `8.5` → `9.4` |
| `aspect*.42` | 구슬을 화면 왼쪽으로 밀어내는 정도 | `.34` → `.42` |

키우면 더 멀리서, 더 왼쪽에 놓인다. 나머지 로직은 그대로다.

## 조절할 만한 값

전부 `main.js` 위쪽에 모여 있다.

| 상수 | 뜻 |
|---|---|
| `FOLLOW` | 손·화면이 따라오는 속도 (클수록 느긋하다) |
| `HOLD` | 꾹 누르는 시간(`time` 손 / `mouse` 마우스), 꼬집기 판정 기준 |
| `HOVER_STEP` | 목록 첫 칸에 손을 얹고 있을 때 다음 영상으로 넘어가는 간격(초) |
| `SLIDE_TIME` | 목록이 한 칸 미끄러지는 시간 |
| `ASCII_CELL` | 큰 화면 글자 한 칸 크기 (작을수록 촘촘하고 무겁다) |
| `ASCII_RAMP` | 어두움 → 밝음 문자 순서 |
| `ASCII_SAT` / `ASCII_GAIN` | 글자 색의 채도 · 밝기 (키우면 더 쨍하다) |
| `ASCII_FLOOR` | 이보다 어두운 칸은 비워 검정을 남긴다 |
| `BARREL` | 큰 화면이 불룩하게 휘는 정도 (0 이면 평평) |
| `FEAT_W` / `FEAT_H` | 큰 화면 크기 (7:5). `style.css` 의 `.feature` 와 같아야 한다 |
| `PIXEL_BASE` | 썸네일 알갱이 굵기 (키우면 가벼워진다) |
| `FILM_CUT` | 본편을 끊는 지점 (초) |
| `VIDEO_FX` | 영상 색보정·질감 (현재 꺼짐) |

`style.css` 의 `--acc` 하나만 바꾸면 UI 액센트 색이 전부 따라온다.
